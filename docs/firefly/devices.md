# 设备与谱面

## 手柄支持

Phira-Firefly 支持使用**常见游戏手柄**游玩：

- 左摇杆 / 十字键：移动光标、浏览菜单。
- A / B / X / Y：确认、返回、打开联机等常用操作。
- 进入打歌后，手柄按键按谱面音符类型对应不同操作（游玩中用触屏/键盘的按键布局同样适用）。
- 想确认手柄有没有被识别？**LB + RB 长按 3 秒**（或按 F9）可以打开**手柄测试页**，实时显示每个按键和摇杆的状态。

## XC-SIM 谱面

Phira-Firefly 为 XC-SIM 谱面提供了**独立分区**，与官方谱面体系互不干扰：

- **独立账号**：XC-SIM 分区使用独立的登录账号，与官方 Phira 账号分开。
- **独立谱面目录**：XC-SIM 谱面存放在单独的位置（不混进官方谱面目录），下载和管理互不影响。
- **独立服务器**：谱面列表和下载走单独的服务器。

### 玩家怎么用

1. 先在设置里登录 **XC-SIM 独立账号**。
2. 在 XC-SIM 谱面列表里下载想玩的谱面。
3. 下载后即可离线游玩，和普通谱面的游玩方式一致。

::: warning 注意
XC-SIM 谱面使用独立账号与服务器，**不参与**官方谱面的联机与排行。
:::

## 谱面渲染

桌面版可以把谱面**直接渲染成视频**，方便录屏、做手元视频或分享：

1. 在谱面列表里打开一首**已下载的本地谱面**，打开右上角菜单，选择「**渲染**」。
2. 在渲染设置里选择：
   - **视频分辨率**：720p / 1080p / 2K / 4K
   - **视频帧率**：30 ~ 640 FPS
   - **视频编码器**：H.264 / HEVC / AV1
   - **硬件加速**：默认开启，渲染更快（显卡支持时）
   - **结尾时长**：歌曲结束后多保留几秒结算画面
3. 点「开始渲染」后，游戏会在后台渲染整个过程，并显示进度、帧率和预计剩余时间。
4. 渲染完成后会提示，视频文件就在谱面对应的输出目录里。

::: tip 说明
- 渲染全程不需要手动操作，游戏自动"打"完整首谱面。
- 此功能仅桌面版（Windows / macOS / Linux）可用，手机端不提供。
:::
