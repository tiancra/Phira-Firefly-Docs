# 画面与演出

## 动态背景

以前打歌时背景是固定画面，Phira-Firefly 让背景"动"起来了：

- 背景会**从当前歌曲的曲绘里提取代表色**，再实时演算成流动的弥散光影，每首歌都有属于自己的配色。
- 背景还会**跟着音乐低音"呼吸"**——鼓点重的时候，光影会随之起伏，打歌更有沉浸感。
- 不喜欢动态效果？可以在设置里选择 **关闭**、**固定亮度** 或 **动态亮度** 三档，按自己的眼睛和电量来选。

## 歌词显示

谱面如果自带歌词文件（TTML 或 LRC 格式），游玩时屏幕会**同步显示歌词**：

- **逐词高亮**：按歌曲时间轴逐词推进，唱到哪亮到哪。
- **多角色区分**：主唱、合唱、背景人声会以不同样式显示，歌词多的时候也分得清。
- **自动淡入淡出**：歌词按节奏出现和消失，不会糊成一团。

### 给制谱者的小提示

想让自己做的谱面带歌词？在谱面压缩包里放一个歌词文件即可，支持以下文件名：

- `lyrics.ttml` / `lyric.ttml`（TTML 格式）
- `lyrics.lrc` / `lyric.lrc`（LRC 格式）
- `ttml` / `lrc`（无扩展名时按内容识别）

游玩时游戏会自动读取并解析。详细说明见[谱面标准 · 歌词](/chart-standard/extra/lyrics)。
