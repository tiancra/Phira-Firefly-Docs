# 联机与账户

## 多人游戏服务器切换

联机不再只能连官方服务器：在**设置 → 多人游戏服务器**里可以管理多个服务器地址。

- **添加**：填写服务器地址（格式为 `主机:端口`，例如 `192.168.1.100:27016`）并保存。
- **选择**：从列表里选一个作为当前使用的服务器，下次连接多人游戏时自动使用。
- 未添加/未选择服务器时，进入多人游戏会提示"请先添加并选择多人服务器"。

配合自建的联机服务器，可以和朋友在私服上玩。

## 本地谱面联机

Phira-Firefly 允许**自己下载到本地的谱面**也能和朋友联机游玩，不再局限于服务器上已有的谱面。创建房间、加入房间的流程和原版一致，房间内谱面由房主决定。

## 成绩上传

- 多人游戏结束后，成绩可以**上传**到服务器（是否开放由服务器端决定，与游玩无关）。
- 上传失败不会影响本地游玩，重试或下次游玩时会再尝试。

## 稳定性改进

多人连接相关的基础设施做了重做（使用独立的服务器组件），连接稳定性更好，掉线重连体验更顺。
