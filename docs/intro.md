# 简介

欢迎来到 **Phira-Firefly 文档**。

本仓库由 [phira-docs](https://github.com/TeamFlos/phira-docs) 改编而来，保留了原版 Phira 的全部文档内容，并在此基础上加入了 Phira-Firefly 的新增功能说明：

- 新增功能按分类整理在 [新增功能](/firefly/) 章节；
- 对原版内容的改动（如谱面歌词、构建说明）直接融入 [谱面标准](/chart-standard/) 与 [构建指南](/phira_build_guide/) 对应章节。

## 这是什么

**Phira-Firefly** 是 [Phira](https://github.com/TeamFlos/phira) 的分支，一款受 Phigros 启发的跨平台音乐节奏游戏，使用 Rust 开发。

- 包含原版 Phira 的全部功能
- 新增跳过曲目、动态背景、歌词显示、新手教程、崩溃界面、文言本地化、手柄支持、XC-SIM 谱面分区、本地谱面联机等特性
- 当前版本：`0.9.4-CBT1`

## 翻译

Phira-Firefly 游戏本体支持包括英语、简体中文、繁体中文、文言（zh-LZH）、日语、韩语、俄语、法语等在内的多种语言。文档站点的多语言版本（如 `/en/`）属于后续计划，欢迎参与翻译工作。
