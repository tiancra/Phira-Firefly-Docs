# 新手引导与界面

## 首次启动向导

第一次打开 Phira-Firefly 时，会有一个**向导**一步步带你完成初始设置——选择语言、调整画面、设置判定偏移等，不用自己满菜单找。中途想跳过也可以随时退出。

## 新手教程

游戏内置了一段**新手教程**，教你怎么打歌：

- 从设置里随时可以重新观看，或者关闭（不想再看到教程弹窗）。
- 教程会演示点击、长按、滑动等基础操作，跟着做一遍就能上手。

## 崩溃界面

游戏出错（崩溃）时不会再"啪"地一下直接消失，而是显示一个专门的界面：

- 界面上会给出一个**错误码**，方便向开发者反馈时说明"是哪种问题"。
- 点击界面可以查看**更详细的错误信息**，帮助判断是设备问题还是谱面问题。
- 错误信息会自动追加记录到 `crash.log` 文件，反馈问题时带上它会很有帮助。

::: tip 遇到崩溃怎么办
截图错误码（或 crash.log 内容），连同设备和谱面信息一起发给开发者，就能快速定位问题。
:::

## 启动界面

游戏启动时有一个新的**开场画面**，点击即可跳过等待，直接进入主界面。

## 窗口与图标

- 桌面版窗口标题会显示当前歌曲名等信息。
- 游戏自带了独立的图标（不是默认的占位图标）。
- 部分资源内嵌进程序，界面上的输入框是专为游戏重做的样式，输入文字更顺手。

## 游戏内输入框

在游戏内需要输入文本（比如搜索、填房间号）时，用的是**游戏自带的输入框**，不再依赖系统弹窗，跨平台体验一致。

## 系统播放控件（SMTC）

Windows 版支持把游玩中的音乐接入系统的媒体播放控件（SMTC）：

- 打开**设置 → 兼容系统播放控件**后，游戏会出现在 Windows 的音量浮层 / 媒体控件里。
- 浮层上会显示当前**曲名、作曲、曲绘**，还能看到播放进度条。
- 用键盘上的**媒体键**或点击浮层按钮就能控制游戏：
  - 播放 / 暂停 → 继续 / 暂停游玩
  - 上一首 → 退出当前谱面
  - 下一首 → 触发[跳过曲目](./gameplay#跳过曲目)
- 开启后，配合 **Lyricify** 之类的桌面歌词软件，还能在桌面上显示歌词。

::: tip 说明
此功能仅 Windows 桌面版可用，默认关闭，在设置中自行开启。
:::
