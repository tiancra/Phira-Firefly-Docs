# 玩法与操作

## 跳过曲目

Phira-Firefly 提供了「跳过曲目」（TRACK SKIP）功能：**快速结束当前这次游玩，直接进入结算界面**查看结果（但不保存成绩）。

::: tip 注意
跳过曲目**不是用来切歌的**——想退出谱面，暂停菜单本身就有退出选项。跳过的用途是给当前游玩"快速收尾"：不用把整首歌打完，也能看到结算。
:::

触发方式：

| 输入方式 | 操作 |
| --- | --- |
| 键盘（桌面） | 长按 **Alt + S** |
| 触屏 | 四指同时按住屏幕四个角 |
| 手柄（桌面） | **LB + RB + LT + RT** 四键组合 |
| Mod 特殊触发 | 开启「突然死亡（AP/FC）」Mod 时，失误会直接触发跳过（见下文） |

### 跳过时会看到什么

- **跳过进度条**：触发后屏幕顶部出现一条进度条，随时间慢慢增长；松开按键或手指后进度条会回缩，可以随时取消。
- **3 秒倒计时**：进度条区域显示 3 秒倒计时，提示"即将跳过谱面"。
- **跳过完成**：画面以全屏黑色遮罩过渡，中央显示跳过提示，随后进入结算界面。
- **音乐不中断**：跳过期间音乐会继续播放，谱面时间也不会暂停，节奏不会断。

### 成绩与记录

- 跳过曲目后**不会保存成绩**，也不会把记录上传（与「自动游玩」等不计成绩的 Mod 一样处理）。
- 多人游戏里跳过结果会延迟到歌曲结束才显示，避免中途退出影响房间里的其他玩家。
- 跳过状态会在重试或结算后正确重置，不会重复触发。

## 血条 Mod

在选歌界面开启 Mod 时，可以给游玩加上一条**血条**：

- 判定越差（Miss 等），血量扣得越多。
- 血量扣完，歌曲直接结束。
- 适合想挑战自己、追求全程稳定发挥的玩家。

## 突然死亡 Mod 的改动

原版的「突然死亡」Mod 在出现非完美判定或连击中断时会**直接失败**。

在 Phira-Firefly 中，开启该 Mod 后失误**不再直接失败**，而是触发[跳过曲目](#跳过曲目)（自动进入结算流程）。想保持原版"失误即结束"体验的玩家，可以选择不开启这个 Mod，或者使用普通的失败规则游玩。

## 偏移校准试玩

游戏内集成了偏移（判定延迟）校准的小玩法，可以在设置偏移时边听边调整，不用切出去用别的工具。
