# 更新日志

当前版本：**0.9.4-CBT3**。按类别整理了本分支相对原版新增与改动的功能，方便快速了解。

## 玩法

- **跳过曲目**：长按 Alt+S、四指按住屏幕四角或手柄组合键，快速结束当前游玩并进入结算（带进度条与 3 秒倒计时）；跳过不计成绩、不上传记录。
- **血条 Mod**：新增可选的游玩血条，扣完即结束。
- **突然死亡 Mod 改动**：失误不再直接失败，而是触发跳过曲目。
- **偏移校准试玩**：游戏内集成了判定偏移校准玩法。

## 画面与演出

- **动态背景**：从曲绘提取代表色实时演算流动光影，随低音"呼吸"；设置提供关闭/固定亮度/动态亮度三档。
- **歌词显示**：支持 TTML / LRC 歌词，逐词同步、多角色区分。

## 新手引导与界面

- **首次启动向导**：引导完成初始设置。
- **新手教程**：内置教学，可随时重看或关闭。
- **崩溃界面**：出错时显示错误码与详细信息，并写入 crash.log。
- **启动界面**：新的开场画面，可点击跳过。
- **窗口与图标**：标题栏显示歌曲名，内置独立图标，输入框为游戏内实现。
- **系统播放控件（SMTC）**：Windows 媒体浮层显示曲名/作曲/曲绘，媒体键控制暂停/退出/跳过，可配合桌面歌词软件。

## 本地化

- **文言**：新增完整的文言文翻译（zh-LZH），设置中可选。

## 设备与谱面

- **手柄支持**：菜单与游玩均支持手柄，含手柄测试页（LB+RB 长按 3 秒或 F9）。
- **XC-SIM 谱面**：独立账号、独立目录、独立服务器的谱面分区。
- **谱面渲染**：桌面版可把谱面自动渲染成视频，可选分辨率（720p~4K）、帧率（30~640）、编码器（H.264/HEVC/AV1），支持硬件加速。

## 联机与账户

- **本地谱面联机**：本地谱面可参与多人房间。
- **成绩上传**：多人成绩可上传（由服务器端决定是否开放）。
- **联机稳定性改进**：服务器组件重做，连接更稳定。

## 面向开发者的改动

- 谱面可附带歌词文件（详见[谱面标准 · 歌词](/chart-standard/extra/lyrics)）。
- 构建流程基本沿用原版，详见[构建指南](/phira_build_guide/)。
- 内部渲染管线重构（跨平台画面表现统一）。
