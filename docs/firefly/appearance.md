# 界面外观

## XCHS UI 布局

Phira-Firefly 提供两套界面布局，随时可以切换：

- **Official**：原版 Phira 界面（左侧竖排导航）。
- **XCHS UI**：参考 XC-SIM 的粉色梅紫风格界面，重做了主页、选曲、设置、资源包、消息等页面。

切换位置：**设置 → 常规 → UI 布局**，选择后重启游戏生效。

XCHS UI 的几个特色：

- 主页：大曲绘背景 + 底部粉色标题，左侧导航卡片。
- 选曲页：顶部梅紫栏 + 粉色装饰，左侧竖排分类胶囊（Local / Ranked / Special / Unstable / Popular / XcSim），右侧大圆角内容卡片带粉色光晕描边。
- 设置 / 资源包 / 消息：梅紫卡片风格，资源包选中显示粉色边框 + "♡ Active"。

## 主题

游戏支持**主题包**（一套封面 + 纹理 + 音频资源的组合），在设置 → 主题中管理：

- **应用**：选择主题后重启游戏生效。
- **导入**：把主题包放进游戏能识别的目录即可导入，导入后出现在主题列表。
- **删除**：不需要的主题可以删除。
- **查看信息**：每个主题显示名称、简介和封面。

游戏自带一个默认主题（default），首次打开即可使用。

::: tip 说明
主题改变的是主界面等菜单的外观与音效，不影响游玩判定与谱面表现。
:::

想自己制作主题？请看[主题开发指南](./theme-dev)。
