# 新增功能总览

**Phira-Firefly** 是 [Phira](https://github.com/TeamFlos/phira) 的分支，保留了原版全部功能，同时加入了不少新东西。这里按类别整理了这些新增功能——全部站在玩家的角度介绍：怎么用、有什么效果、在哪里找。

## 玩法与操作

| 功能 | 一句话说明 |
| --- | --- |
| [跳过曲目](./gameplay#跳过曲目) | 长按 Alt+S（或四指按住屏幕四角）快速结束当前游玩并进入结算，不计成绩 |
| [血条 Mod](./gameplay#血条-mod) | 给游玩加一条血条，血量扣完就结束 |
| [突然死亡改为跳过](./gameplay#突然死亡-mod-的改动) | 开「突然死亡」失误后不再直接失败，而是触发跳过流程 |

## 画面与演出

| 功能 | 一句话说明 |
| --- | --- |
| [动态背景](./visuals#动态背景) | 背景会跟着曲绘颜色流动，还能随音乐低音"呼吸" |
| [歌词显示](./visuals#歌词显示) | 谱面自带的歌词会在游玩中同步显示 |

## 新手引导与界面

| 功能 | 一句话说明 |
| --- | --- |
| [首次启动向导与新手教程](./experience#首次启动向导) | 第一次打开游戏会带你一步步完成设置，还有内置教程 |
| [崩溃界面](./experience#崩溃界面) | 游戏出错时不再直接退出，会告诉你哪里出了问题 |
| [启动界面](./experience#启动界面) | 新的开场画面，点击就能跳过等待 |
| [系统播放控件（SMTC）](./experience#系统播放控件smtc) | Windows 媒体浮层显示曲名/曲绘，媒体键可控制游戏，还能配合桌面歌词软件 |

## 本地化

| 功能 | 一句话说明 |
| --- | --- |
| [文言本地化](./l10n) | 完整的文言文翻译，设置里即可切换 |

## 设备与谱面

| 功能 | 一句话说明 |
| --- | --- |
| [手柄支持](./devices#手柄支持) | 用手柄也能浏览菜单、打歌 |
| [XC-SIM 谱面](./devices#xc-sim-谱面) | 独立账号体系的新谱面分区，和官方谱面互不干扰 |
| [谱面渲染](./devices#谱面渲染) | 桌面版可把谱面自动渲染成视频（可选分辨率/帧率/编码器） |

## 联机与账户

| 功能 | 一句话说明 |
| --- | --- |
| [本地谱面联机](./multiplayer#本地谱面联机) | 自己下载的谱面也能和朋友联机 |
| [成绩上传](./multiplayer#成绩上传) | 多人游戏成绩可以上传（由服务器决定是否开放） |
